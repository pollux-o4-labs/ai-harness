# 주입기 도입 뒤 갚을 리팩토링이 없다

> **BLUF:** 새 코드를 훑고 고칠 스멜이 없다고 판정한 실측.

## 무엇을 쟀나

공용 안내 주입기가 들어온 뒤 새 코드를 리팩토링 관점으로 훑었다.

## 판정

### 종료 코드 상수 — 합치지 않는다

세 생성기가 같은 수치를 각자 정의한다.
처음에는 정본 분열로 보았으나 코드에 이미 근거가 있었다.

각 모듈이 자기 종료 코드 집합을 소유한다.
값이 같은 것은 우연이고 뜻이 같은 것은 아니다.
합치면 한쪽이 코드를 늘릴 때 다른 쪽까지 묶인다.

### 생성기 추가 비용 — 흩뿌리기가 아니다

주입기를 넣으며 손으로 고친 곳은 둘뿐이었다.
서브커맨드 선언 한 줄과 마커 등재 한 줄이다.

둘 다 정본 표라 나머지가 자동으로 파생된다.
새 모듈과 그 검사는 당연한 몫이고 인덱스는 기계가 만든다.

### 공용 모듈 — 얕지 않다

지우면 두 소비처가 정규식 조립과 오프셋 계산, 원자적 쓰기를 각자 다시 쓴다.

### 진입점 길이 — 정당하다

분기가 둘이고 나머지는 위임 호출이다.
판정 로직이 아니라 흐름을 잇는 자리다.

## 왜 없나

이 슬라이스가 리팩토링을 겸했다.
공용 모듈을 뽑는 것이 첫 커밋이었고 기능은 그 위에 얹혔다.

## 재판정 조건

세 번째 생성기가 생기면 다시 잰다.
그때도 손으로 고칠 곳이 둘이면 이 판정이 유지된다.
