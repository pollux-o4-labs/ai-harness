# ANSI 색 코드가 감시 장치를 묵인 건너뛰게 만들다

> **BLUF:** ANSI 색 코드가 경로 탐지를 무효화해 유일한 감시 장치가 묵인 건너뛰기로 통과했다.

## B (하지 말 것)

감시 장치를 단일 탐지 수단에 의존시키고 실제 실행 여부를 검증하지 않기.

- 문제: 설치본 신선도 대조 테스트가 `pytest.skip`으로 묵인 통과했다.
- `test_installed_bundle_matches_source.py`는 캐시 재사용 사고를 막는 유일한 감시 장치였다.
- 원인은 `uv tool dir` 출력이었다.
- `capture_output`으로 출력을 받아도 `uv`가 경로를 ANSI 색 시퀀스로 감싸 내보냈다.
- 실제 값은 ESC 대괄호 36m로 시작해 ESC 대괄호 39m로 끝났다.
- `Path`가 색 시퀀스까지 경로로 받아 존재하지 않는 디렉터리가 되었다.
- 탐지 함수 `_installed_package_dir`가 `None`을 반환하여 테스트를 `pytest.skip`으로 통과시켰다.
- 탐지 동작을 확인하는 `test_detector_actually_finds_the_global_install`도 같은 호출을 사용했다.
- 결국 감시 장치의 감시 장치까지 함께 건너뛰었다.
- 두 번째 결함으로 대조 루프가 `iterdir`로 최상위 파일만 세어 하위 폴더 조문 19건을 누락했다.

## G (대신 할 것)

환경변수를 정제하고 대조 루프를 상대 경로 전수 탐색으로 전환한다.

- `uv tool dir` 호출 시 `NO_COLOR=1` 환경변수를 전달하여 색 시퀀스를 제거한다.
- 대조 루프를 `iterdir`에서 `rglob`과 상대 경로 키 구조로 변경한다.
- 조치 후 건너뛰기가 사라지고 테스트 3건이 모두 실행되는 것을 확인했다.
- 건너뛰기는 통과와 동일한 색상으로 보고된다.
- 감시 장치를 생성할 때 해당 장치가 실제로 실행되는지 확인하는 별도 축이 필요하다.
- 검증 축이 대상과 동일한 취약점을 공유하면 검증 역할을 수행하지 못한다.
