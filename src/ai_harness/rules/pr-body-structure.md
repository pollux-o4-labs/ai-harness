# 규칙 05 — PR 본문의 구조와 분량

> **BLUF:** PR 본문의 필수 섹션·분량 예산·용어 풀이·검수 자기신고에 관한 사항.

## 왜 필요한가

총량만 걸면 저자가 어느 섹션을 줄일지 스스로 고른다.

서사가 붙기 쉬운 요약이 부풀고, 리뷰어에게 정작 필요한 검증이 0자가 된다.

섹션별 상한은 그 선택권을 박탈한다.

## 규칙

### 제1조 (필수 섹션)

PR 본문은 템플릿의 필수 섹션을 모두 갖춰야 한다.

해당 사항이 없는 섹션을 삭제해서는 아니 되며 "없음"이라고 적어야 한다.

템플릿에 없는 섹션을 추가해서는 아니 된다.

다만, 면제 섹션은 형태만 강제한다.

### 제2조 (섹션별 분량 예산)

각 섹션은 분량 예산을 초과해서는 아니 된다.

예산 수치를 이 조문에 재서술하지 아니한다.

위반 시 검사기가 실측값과 예산을 함께 보고한다.

### 제3조 (검사 우회 금지)

본문을 검사기가 들여다볼 수 없는 방식으로 PR을 열어서는 아니 된다.

본문은 파일이나 인자로 명령에 실어야 한다.

### 제4조 (내부 용어 풀이)

PR 본문은 이 저장소를 모르는 제3자가 한 번에 읽을 수 있어야 한다.

내부 용어 풀이는 [한 글에 한 어휘 층위](one-register-per-document.md) 제3조를
따른다.

PR 본문에서 추가되는 것은 이 요구가 확인 절의 자기신고 항목으로 함께 걸린다는
점뿐이다.

### 제5조 (확인 체크리스트)

PR 본문은 확인 절에 체크리스트를 갖춰야 한다.

완료는 머지 시점에만 요구하고, 생성 시점에는 절의 존재만 본다.

이 절은 분량 예산에 산입하지 아니한다 — 고정 문구라 저자가 축소하지 못한다.

이 조가 강제하는 것은 글이 아니라 글자 `x` 하나다.

체크는 참의 증거가 아니라 리뷰어가 반증할 수 있는 자기신고다.

## 강제 수단 (정직 표기)

`check_pr_body`가 훅으로 배선되어 PR 생성·머지를 리젝한다.

검사는 룰 기반이며 언어 모델을 부르지 않는다.

섹션 목록·예산 수치·면제 목록의 정본은 그 모듈과 폼 파일이다.

내부 용어 풀이에는 기계 정본이 없다 — 어휘가 무한 집합이라 목록을 두지 않는다.

그 판정은 동봉 좌석 `reviewer-style`이 질문으로 수행한다.

체크 항목의 참거짓은 재지 못한다 — 그 축은 자기신고이며 리뷰어 판정에 의존한다.
