# 규칙 16 — 경로 참조는 영구 저장 여부에 맞춘다

> **BLUF:** 경로 표기는 대상 경로의 저장소 저장 여부에 따라 상대 경로와 절대 경로로 구분한다.

## 왜 필요한가

저장되어 이동하는 위치에 절대 경로를 쓰면 환경 변경 시 참조가 파손된다.

세션 내에 휘발하는 기계 입력에 상대 경로를 쓰면 미존재 경로 참조 오류가 발생한다.

## 규칙

### 제1조 (인간 대상 서식)

사람이 읽는 자리에는 상위 폴더 한 단계와 파일명으로 구성한 최소 식별자를 작성하고 위치 지정 시 행 번호를 덧붙여야 한다.

사람이 읽는 문서에 절대 경로를 적어서는 아니 된다.

### 제2조 (저장되는 기계 참조)

커밋되어 이동하는 설정과 스크립트에는 저장소 루트 기준 상대 경로를 작성해야 한다.

.gitmodules, CLAUDE.md, 셸 스크립트, CI 설정이 이에 해당하며 파일 내 절대 경로 배치를 금지한다.

저장소 외부를 가리켜야 하면 환경변수로 뿌리 경로를 받아야 한다.

### 제3조 (휘발하는 기계 입력)

세션 안에서만 존재하는 셸 명령, 도구 인자, 위임 프롬프트에는 대상의 절대 경로를 작성해야 한다.

휘발성 기계 입력은 작업 디렉터리가 확정되지 아니한다.

뿌리 경로 지정 후 상대 경로를 사용하는 방식의 효용은 실측 근거가 없어 유보한다.

### 제4조 (모호성 처리)

경로 표기 서식은 사람이나 기계의 구분이 아닌 영구 저장 여부를 기준으로 판정해야 한다.

저장 여부가 모호하면 저장되는 경로로 보고 상대 경로를 작성해야 한다.

## 강제 수단 (정직 표기)

기계 게이트가 없으며 사람 확인과 리뷰어 판정에 의존한다.
