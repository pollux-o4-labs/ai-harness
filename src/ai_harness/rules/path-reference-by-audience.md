# 규칙 16 — 참조 경로는 읽는 주체에 맞춘다

> **BLUF:** 참조 경로는 읽는 주체가 사람인지 기계인지에 따라 서식을 구분한다.

## 왜 필요한가

사람이 읽는 자리에 전체 경로를 적으면 가독성이 떨어지고 분량이 늘어난다.

기계가 받는 자리에 약식 경로를 적으면 미존재 경로 생성이나 참조 오류가 발생한다.

## 규칙

### 제1조 (인간 대상 서식)

사람이 읽는 자리에서는 상위 폴더 한 단계와 파일명으로 구성된 최소 식별자를 작성해야 한다.

위치 지정이 필요하면 파일명 뒤에 행 번호를 덧붙여야 한다.

사람이 읽는 문서에 절대 경로를 적어서는 아니 된다.

### 제2조 (기계 대상 서식)

기계가 받는 자리에서는 대상의 절대 경로를 작성해야 한다.

도구 인자, 위임 프롬프트, 셸 명령은 기계가 받는 자리에 해당한다.

위임 프롬프트와 셸 명령에서 경로를 약식으로 표기해서는 아니 된다.

### 제3조 (모호성 처리)

읽는 주체가 사람인지 기계인지 모호하면 절대 경로를 작성해야 한다.

## 강제 수단 (정직 표기)

기계 게이트가 없다.

사람 확인과 리뷰어 판정에 의존한다.
